# Nakshatra Hotel & Resort

Official website experience for Nakshatra Hotel & Resort in Khargone, Madhya Pradesh.

## Website features

- Luxury rooms with real image galleries, amenities and guest-based meal packages
- Pay-at-hotel booking flow
- Ground-floor guest pool and privately bookable third-floor rooftop pool
- Weddings, wedding hall, wedding garden and complete event planning
- Birthday parties, pool parties and personal celebrations
- Business meetings and conference facilities
- Restaurant, parking, local information and property gallery
- Interactive Nakshatra Concierge for questions, images, prices and booking guidance

## Development

```bash
npm install
npm run dev
npm test
```

The production build uses vinext and is configured for OpenAI Sites hosting.
